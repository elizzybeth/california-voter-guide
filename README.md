# California, considered

Independent guide to the November 3, 2026 California statewide propositions.
Static HTML, CSS and JavaScript, suitable for GitHub Pages with no dependencies.

Source content is in `data.json`. Run `python3 build.py`
from the repository root after editing content. Commit the generated HTML too.

The official Secretary of State per-proposition pages supply provisions,
fiscal summaries and attributed campaign positions. FPPC's November 2026
top-contributor disclosures supply selected donor examples. The generated
page links to these sources at each measure and explains coverage limitations.

Editorial assessments distinguish inference from verified provisions and
campaign claims. The guide offers no personal political profiling or voting
recommendations. It is a dated snapshot, not a live tracker.

No analytics, external fonts, cookies, backend or storage. The content remains
available with JavaScript disabled; JS adds search, filtering and printing.
Print styles include every measure even when screen filters are active.

Standalone GitHub Pages project. Publish the repository root from the main branch.
No custom domain is configured.
